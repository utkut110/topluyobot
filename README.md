# topluyobot
Merhaba Bu Yeni Topluyonun Örnek Bir Bot Yapısıdır İyi Kodlamalar

KULLANIMI

1 - Öncelikle topluyo.com ' a giderek bir bot hesabı oluşturun.

2 - Hesap ayarlarına girin, cihazlar kısmına tıklayıp Client Key i kopyalayın.

3 - Kopyaladığınız Client Key i .token.json un içine yapıştırın. (Örnek Olarak "834u38r8u8f83453759873"

4 - Dosya içinde komut satırını açıp node index.js yazarsanız botunuz aktif olacaktır.

Gerisi size kaldı içine lomut ekleyebilir geliştirebilirsiniz.
